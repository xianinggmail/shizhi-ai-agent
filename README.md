# 拾知 · 新传保研学习助手（论文精读升级）

## 当前启动方式

本目录已是更新后的可运行项目。电脑日常使用双击“本机启动并配置.cmd”；手机与电脑同一 Wi-Fi 使用双击“手机访问启动.cmd”，详见“手机访问说明.md”。若旧服务正在运行，先保存草稿并在原窗口按 Ctrl+C，再启动新版。

现有资料保存在本目录 data 中，安全配置保存在 .secrets 中。不要把这些目录上传 GitHub。历史“安装并打开.cmd”用于旧 D 盘目录迁移，当前使用不需要运行它。

## 论文精读与练习

- 上传可提取文字的 PDF，或勾选已有资料。一次选择同一老师的1—3篇；填写老师姓名作为整理标签即可，无需填写作者、年份或勾选人工确认。共同署名论文的主张不等于某位老师的个人独创。
- 点击“查看处理范围”只做本地检查，显示可提取页、字符量、分段、已有缓存和预计最多调用次数，不调用模型。
- 点击“精读并生成训练题”才发送所选全文文字。每段最多16000字符，全文逐段处理，不静默截断；每篇上限12万字符。空白页、扫描页、多栏和图表可能影响提取质量，需核对。
- 精读提取研究问题、理论、论点、方法、发现与局限；某个维度缺少依据时允许缺失。每点有原文片段与物理页，可查看完整提取页和 PDF。
- 每批目标3道名词解释、2道论述题，也可单独选择题型。名词解释参考答案目标150—300字；论述题目标600—1000字。材料不足或核验失败时保留合格题并说明数量与长度偏差，不编造凑数。
- 多篇论述题须引用每篇所选论文的观点。答案逐段标注“论文作者主张”“论文引用的他人理论”“AI综合分析”，可从段落回到观点，再核对原文。
- 先显示题目，再点击查看参考答案。可选作答草稿自动保存；展开状态重启后保留。不自动评分，不计入原有知识点自评记录。

这些是训练题和参考答案，不预测真实考题。引用编号核验仅保证来源存在，不能保证语义、作者归属或解释必然正确，必须人工核对。

## 模型、费用与保存

沿用现有 DeepSeek 安全配置。默认模型 deepseek-flash，可使用 DEEPSEEK_MODEL 切换 deepseek-v4-pro。后端使用官方 HTTPS 接口、JSON输出，凭据只在本机读取，不进入浏览器、SQLite 或升级包。不要在聊天提供密钥。

费用按你确认不设上限。一批可能包含多个分段请求和一次综合出题；计划页面显示最多请求次数。请求失败或超时可能已计费，会停止后续步骤，不自动重试。成功分段按模型、提示版本、全文和元数据缓存；分别生成另一题型可复用精读缓存。缓存不等同于第三方账单或免费服务保证。

“免费核验本地结果”不读取密钥、不调用模型；缺少后续响应会说明。“继续未完成步骤”需要确认，先复用成功步骤，再请求未完成步骤，可能新增费用。

PDF、提取文本、论文信息、分段响应与用量、精读结果、题目、答案草稿和展开状态保存在本机 data/learning.sqlite3 与 PDF 文件。关闭网页不会取消已启动任务；服务中断后不自动继续付费。重启后可从本机记录核验或继续；页面显示最近40批，其他记录仍保存在数据库。

删除一份材料会删除该材料的缓存，以及涉及它的整批精读、综合响应、题目和答案草稿；其他材料的独立缓存保留。已产生费用不会退回，已发送数据无法由本机删除操作撤回。升级备份不会随材料删除而删除。DeepSeek 的数据处理政策以服务条款为准。

## 原有书籍学习功能

保留学习总览、资料搜索/筛选/排序、PDF上传状态、章节或物理页范围、每次3—5知识点约10分钟、先回忆后核对、自评、续学及未掌握复习。尾批不足3条按实际数量安排。现有学习规则不变，仍没有间隔重复调度或客观掌握评分。

## 2026-10-24 论文精读清晰度与依据约束升级（grounded-v2）
